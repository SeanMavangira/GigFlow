# GigFlow

> All-in-one freelancer management app built for independent workers.

GigFlow helps freelancers manage the business side of their work — from tracking projects and rates to organizing payments and workflow in one clean mobile experience.

---

## Features

- 📁 Project management
- 💰 Rate & payment tracking
- 📊 Freelancer workflow organization
- 📱 Native iOS experience
- ⚡ Simple and lightweight interface
- 🧩 Widget support via GigFlowWidget

---

## Tech Stack

- Swift
- SwiftUI
- Xcode
- iOS Widgets

## Getting Started

### Prerequisites

Before running the project, make sure you have:

- macOS
- Xcode installed
- iOS Simulator or physical iPhone

---

## Installation

1. Clone the repository

```bash
git clone https://github.com/SeanMavangira/GigFlow.git
```

2. Navigate into the project directory

```bash
cd GigFlow
```

3. Open the project in Xcode

```bash
open GigFlow.xcodeproj
```

4. Build and run the app using the iOS Simulator or your device.
